# Project Statement

## Problem Statement
Students need a simple way to record and
track their daily expenses. Without proper
tracking, it can be difficult to understand
where money is being spent.

## Scope
The Student Expense Tracker is a Python
application that helps students record,
view, search and manage their expenses.

## Target Users
- College students
- School students
- People tracking daily expenses

## High-Level Features
- Add expenses
- View all expenses
- Search expenses
- Calculate total expenses
- Find highest expense
- Delete expenses
- Save expenses
